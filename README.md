# VolleyBoard 排协活动看板

VolleyBoard 是一个面向排协内部使用的轻量活动看板。它不是传统社团官网，也不是报名系统，而是把成员最常打开、负责人最常维护的信息放在一个安静、实用的页面里。

项目的第一核心是 **野球实时人数统计**，第二核心是 **赛事赛程、排名、比分和资料沉淀**。群聊仍然负责通知和讨论，网站负责展示当前人数、固定安排、赛事信息和长期资料。

## 项目定位

- 给成员看：今天有没有活动、现在大概多少人、最近有什么比赛。
- 给负责人用：创建野球活动、切换活动状态、维护赛事赛程、录入比分、管理资料。
- 给协会留档：历史活动记录、赛事排名、比赛资料和附件沉淀。

当前版本刻意保持轻量：

- 不做成员登录
- 不做报名系统
- 不做个人主页或论坛
- 不做球数 / 带球统计
- 不做复杂权限系统
- 不做 WebSocket 实时推送

## 功能一览

### 野球活动看板

- 首页展示当前野球活动
- 成员点击「会来 / 到了」统计人数
- 再次点击已选状态可以取消
- 活动结束或取消后禁止继续签到
- 同一浏览器只记录一次，无需登录

### 固定场地安排

- 首页在没有当前活动时显示今日固定安排
- 新增 `/weekly-schedule` 每周固定安排页
- 固定安排只做展示，不会自动生成活动，也不会进入历史统计

每周安排：

| 星期 | 固定安排 | 地点 |
| --- | --- | --- |
| 周一晚上 | 校队训练 | 室内排球场 |
| 周二晚上 | 野球 | 室内排球场 |
| 周三 | 暂无固定安排 | - |
| 周四晚上 | 野球 | 室内排球场 |
| 周五晚上 | 校队训练 | 室内排球场 |
| 周六晚上 | 野球 | 室内排球场 |
| 周日晚上 | 校队训练 | 室内排球场 |

### 管理员活动管理

- 创建、编辑、删除野球活动
- 活动状态：未开始、进行中、已结束、已取消
- 根据今日固定安排快捷创建野球活动草稿
- 复制群公告
- 查看预计人数、已到人数和峰值到场人数

### 赛事模块

- `/schedule` 赛事列表
- `/schedule/[id]` 赛事详情
- 赛事内赛程、比分、局分、排名
- 队伍按赛事管理，适合每次比赛重新分队
- 首页展示最近比赛

### 赛事资料

- 支持添加外部资料链接
- 支持上传图片、PDF、表格等本地文件
- 上传文件保存到 Supabase Storage，不保存到 Render 本地文件系统
- 公开赛事详情页统一展示资料

### 管理员 Agent 助手

`/admin/assistant` 是只面向管理员的维护助手。它使用 DeepSeek 解析自然语言，但不会直接改数据库。

支持：

- 生成群公告
- 查询赛事信息
- 创建赛事
- 批量导入队伍
- 批量创建赛程
- 录入比分 / 局分

所有写操作都遵循：

```text
预览 -> 管理员确认 -> 执行
```

Agent 不支持删除操作，也不允许执行任意 SQL。

### 管理员使用手册

`/admin/manual` 提供面向社团管理员的使用说明，覆盖野球管理、赛事管理、资料管理、Agent 助手和常见问题。

## 设计原则

VolleyBoard 的目标不是“功能越多越好”，而是让成员真的愿意打开、负责人真的愿意维护。

所以当前版本优先保证：

- 首页第一屏能快速看到当前活动和人数
- 不登录也能签到
- 负责人用少量操作就能创建和维护活动
- 赛事信息能沉淀下来，不散落在群文件和聊天记录里
- 固定安排和真实活动分开，避免误把默认安排当成签到活动

## 项目状态

当前项目已经具备轻量内部活动看板的完整可用形态：

- 野球人数统计可用
- 固定安排展示可用
- 活动后台可用
- 历史统计可用
- 赛事模块可用
- 赛事资料上传可用
- 管理员 Agent 助手可用

后续如果继续扩展，建议仍然保持“小而实用”的方向，优先优化管理员维护体验和成员打开速度。
